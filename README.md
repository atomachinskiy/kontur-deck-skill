# kontur-deck — скилл презентаций в каноне Контура

Скилл для Claude Code: сборка презентаций по бренд-гайдам Контура — 28 эталонных
шаблонов слайдов (`templates.html`), дизайн-токены (`tokens.json`, `kontur-deck.css`),
правила вёрстки (`DESIGN-RULES.md`), рендер в PDF (`render/`, `render.js`)
и экспорт в Google Slides (`google-slides/`).

## Установка

```bash
git clone git@github.com:atomachinskiy/kontur-deck-skill.git ~/.claude/skills/kontur-deck
```

Шрифты Lab Grotesque добавьте из внутреннего источника Контура (лицензия).

## Использование

«Собери деку по канону Контура: …» — агент возьмёт шаблоны и прогонит линтер вёрстки.
Живой пак: им собраны деки стратсессии УМ, КСР и хакатона.

⚠️ Шаблоны и канон — внутренние материалы Контура. Репозиторий приватный;
публикация наружу только после согласования с Контуром.
